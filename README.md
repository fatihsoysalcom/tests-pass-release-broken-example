# Tests Pass Release Broken Example

This example demonstrates how software can appear to pass all tests, yet still contain critical bugs that lead to a 'broken release'. It shows a function with an intentionally missing business rule, where existing tests pass, but a specific production-like scenario exposes the flaw.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
